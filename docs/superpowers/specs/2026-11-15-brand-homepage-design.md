# 기억・연 / Kiokuyeon 브랜드 홈페이지 — 설계서

작성일: 2026-11-15 · 대상 저장소: `azabumin2/kiokuyeon` (GitHub Pages + Firebase `kiokuyeon`, Spark 무료 요금제)

## 1. 목적과 배경

- 국제결혼중개업체 「미래결혼정보 서울」이 운영하는 한일 결혼 상담 브랜드 **「기억・연 / Kiokuyeon」**의 공식 홈페이지를 kiokuyeon.com에 만든다.
- 주요 방문자: 한국 남성과의 결혼에 관심 있는 일본 성인 여성, 일본 여성과의 결혼을 진지하게 생각하는 한국 성인 남성, 그 가족, 해외 이용자·협력처.
- 성공 기준: 첫 화면에서 따뜻하고 믿을 수 있다는 인상을 주고, **개별 상담 신청**으로 이어진다. 등록·보험 정보로 안심감을 준다.
- 사용자가 준 상세 프롬프트(2026-11-15 대화)가 내용·톤·카피의 기준이다. 이 문서는 그것을 어떻게 만들지를 정한다.

## 2. 목표 / 비목표 / 하지 말 것

**목표**
- 한국어·일본어·영어 3개 언어, 언어 전환 시 같은 페이지로 이동.
- 프롬프트의 10개 페이지와 9단 구성 톱 페이지.
- 관리자 화면에서 **설정값만** 바꿀 수 있게 한다(사용자 결정, 2026-11-15).
- 상담 신청 폼 → 관리자 화면에 배지로 표시.
- 휴대폰 우선, 빠른 표시, 절제된 움직임.

**비목표 (이번에 하지 않음)**
- 문장·사진을 관리자 화면에서 편집하는 기능(문장 수정은 코드로 반영).
- 온라인 결제, 회원끼리 열람, 챗봇, 블로그 편집기.
- 이메일·푸시 알림(Spark 요금제 제약).

**하지 말 것 (기술적으로 돌아가도 실패로 본다)**
- 가짜 후기·실적·숫자, 「반드시 성혼」「정부가 보증」「모든 손해 보상」 같은 표현.
- 여성을 상품 목록처럼 나열하는 구성.
- 존재하지 않는 LINE·카카오 계정, QR, 도쿄 지점·일본 법인·인증 표기.
- AI 생성 인물 사진을 실제 회원·성혼자로 소개하는 것.
- 확인되지 않은 요금·무료 여부·담당 언어를 임시 값으로 공개하는 것.

## 4. 방식 (Approaches)

1. **정적 HTML + 작은 생성 스크립트 + Firestore 설정 문서 (채택)**
   지금 회원 사이트와 같은 GitHub Pages·Firebase·순수 JS 구성. 3개 언어 × 10페이지는 Python 스크립트가 공통 틀과 언어별 문장 파일에서 HTML을 만들어 저장소에 함께 커밋한다(서버·빌드 서버 불필요). 설정값은 Firestore `site/settings` 문서를 REST로 읽는다.
2. 정적 사이트 생성기(Astro, 11ty 등) + GitHub Actions 빌드 — 기능은 비슷하지만 Node 빌드 체계를 새로 들여야 하고, 은퇴 후 유지·인계가 복잡해진다.
3. WordPress 등 CMS·렌탈 서버 — 문장 편집은 쉽지만 서버 운영·비용이 들고, 사용자가 렌탈 서버를 해지했으며 설정값만 편집하기로 했으므로 맞지 않는다.

→ 1안 채택. 이유: 기존 구성 그대로, 무료, 의존성 없음, 인계가 쉬움.

## 5. 설계

### 5.1 주소 구성
| 주소 | 내용 |
|---|---|
| `/` | 언어 선택 후 이동(저장된 선택 → 브라우저 언어 → 일본어). 자바스크립트 없이도 3개 언어 링크가 보인다. |
| `/ja/`, `/ko/`, `/en/` | 각 언어 톱 페이지 |
| `/{lang}/about.html` 記憶・縁について · `service.html` サービス・サポート · `flow.html` ご利用の流れ・料金 · `stories.html` ご夫婦のストーリー · `column.html` 言葉と文化のコラム · `faq.html` よくある質問 · `company.html` 運営者情報 · `contact.html` 個別相談 · `privacy.html` プライバシーポリシー・利用条件 | |
| `/join/` | **지금의 회원 등록 화면을 옮긴 곳**(현재 `/index.html`). 기능 변경 없음, 자산 경로만 `../assets/`로. |
| `/admin.html` | 관리자 화면(기존) + 「사이트 설정」「상담 신청」 추가 |

- 기존 회원 화면으로 오던 링크(확인 메일의 continue URL 등)는 `/`로 오면 홈페이지가 열리고, 헤더의 「会員ページ / 회원 페이지 / Member login」 버튼으로 `/join/`에 간다. 인증 메일 continue URL은 앞으로 `/join/`이 된다(코드가 `location.pathname` 사용).
- 각 페이지에 `hreflang` 대체 링크, 언어별 `<title>`·description·OGP.

### 5.2 화면·디자인
- 색: 아이보리 `#FAF7F2`, 웜베이지 `#EAE2D8`, 소프트로즈 `#D8A6A0`, 네이비 `#263C50`, 본문 `#333333`.
- 글꼴: 일본어 Meiryo 우선(시스템), 한국어 Noto Sans KR, 영어 Inter(Google Fonts), 제목은 Noto Serif JP/KR를 절제해 사용.
- 넓은 여백, 큰 사진, 읽기 쉬운 글자. 하트·국기는 최소, 강한 빨강·깜빡임 없음. 소리 자동재생 없음.
- 상단: 로고 · 메뉴 · 「한국어｜日本語｜English」 · 회원 페이지 버튼. 휴대폰은 햄버거 메뉴 + 하단 고정 「상담 예약」 버튼.
- 톱 페이지 9단: ①첫 화면(메인 카피·「個別相談を予約する」·「ふたりのストーリーを見る」) ②부부 영상 ③안심 대처 ④말·문화·교제 지원 ⑤상담~결혼 흐름 ⑥한국 본사·일본 활동 ⑦FAQ ⑧상담 안내 ⑨운영자 정보.
- 카피는 프롬프트 문안을 기준으로 각 언어 자연스럽게 다듬는다.

### 5.3 이미지
- 사용자 규칙에 따라 **모든 이미지(사진·로고)는 `openai-image` 스킬로 생성**한다. SVG·CSS로 그리지 않는다.
- 필요 이미지(초안): 로고(「기억・연」+「Kiokuyeon」, 두 점을 잇는 가는 선 모티프), 첫 화면 커플(카페에서 웃는 모습), 나란히 걷는 뒷모습, 함께 요리하는 일상, 상담 장면(대화하는 손·노트), 서울 거리 풍경, OGP 이미지. WebP로 압축, 폭 1600px 이하.
- 인물 사진 아래에 작은 글씨로 「イメージ写真 / 이미지 사진 / Image photo」 표시.

### 5.4 등록·보험 정보
- `company.html`과 톱 ⑨에 3장의 표를 차분한 카드로 표시. 「政府が保証」 등 금지 표현 없음.
- 등록증·보험증권 사본 이미지는 PDF를 이미지로 바꾸고 **생년월일·주민번호를 가린 뒤 사용자가 확인한 경우에만** 게시한다(확인 전에는 표만 표시).
- 보험 기간은 `site/settings`에서 읽는다. 종료일이 지나면 공개 화면에서 보험 카드를 숨기고, 관리자 대시보드에 종료 60일 전부터 「갱신 확인」 경고를 띄운다.

### 5.5 설정값 (Firestore `site/settings`, 누구나 읽기·관리자만 쓰기)
| 필드 | 용도 | 비어 있을 때 |
|---|---|---|
| `freeConsult` (true/false/null) | 「상담 무료」 표시 | 표시 안 함 |
| `fees` {ja,ko,en} 짧은 글 | 요금 안내 | 「상담 시 안내합니다」 |
| `lineUrl`, `kakaoUrl` | 일본어 페이지 LINE, 한국어 페이지 카카오 버튼 | 버튼 숨김, 폼만 |
| `staffInfo` {ja,ko,en} | 담당 언어·응대 시간·통역 비용 | 섹션 숨김 |
| `japanOffice` {status: 'none'/'preparing'/'open', address{ja,ko,en}} | 일본 활동 안내 | 'none'이면 문구만(사무소 언급 없음), 'preparing'이면 「開設準備中」 |
| `videos` [{youtubeId, title{ja,ko,en}, note{ja,ko,en}, country, permission:true}] | 부부 영상(첫 번째가 대표) | 섹션 대신 「準備中」 안내 |
| `insurance` {amount, from, to} | 보험 카드 | 숨김 |
| `registration` {no, date} | 등록 정보 | 3장 표의 값 사용 |
| `japanName` 「未来国際結婚情報」 병기 여부 | 일본 안내명 | 표시 안 함 |

- 공개 페이지는 Firebase SDK 없이 Firestore REST로 이 문서 하나만 읽는다(속도). 읽기 실패 시 기본값으로 표시.
- 관리자 화면에 「サイト設定 / 사이트 설정」 화면을 추가해 위 값을 편집한다. 영상은 YouTube 주소를 붙여 넣으면 ID를 추출하고, 「게재 허가 확인함」 체크가 없으면 저장되지 않는다.

### 5.6 상담 신청 (Firestore `consults`)
- 항목: 呼び名, 居住国・地域, 年代(20대~60대 이상 선택), 希望する連絡方法(LINE/カカオ/メール/電話), **連絡先**(답장에 필요 — 프롬프트 항목에 추가, 내 판단), 相談内容(2000자 이하), 個人情報の取扱いへの同意(필수). 언어·제출 시각 자동 기록.
- 본인확인 서류·소득·건강 정보는 받지 않는다.
- 로그인 없이 제출(새 방문자용). 보안 규칙: 생성만 허용, 필드 화이트리스트·길이·`createdAt == request.time`·`status == 'new'` 검증, 읽기·수정·삭제는 관리자만. 스팸 대책으로 숨은 입력칸(허니팟)과 같은 브라우저 연속 제출 60초 제한.
- 관리자 화면: 상단 메뉴에 「相談申込」 배지(새 건수), 목록·상세·상태(신규/연락함/완료)·메모.

### 5.7 회원 영역과의 분리
- 홈페이지 페이지에는 회원 사진·이름·연락처를 절대 싣지 않는다. Firebase 인증 SDK는 `/join/`과 `admin.html`에서만 로드.

### 5.8 기타
- 개인정보 처리방침·이용조건: 한국 「결혼중개업법」 상 사업자 정보 표시, 수집 항목(상담 폼), 이용 목적, 보관·삭제, 문의처를 3개 언어로. 법률 문구는 일반 템플릿 수준이며 **공개 전 사용자 확인 필요**로 표시.
- 컬럼: 처음 3편(연락 빈도, 가족과의 거리감, 말의 뉘앙스)을 일반적 조언 수준으로 작성, 통계·사실 주장 없음.
- 스토리: 영상이 없으면 「準備中」. 지어낸 사연 없음.
- FAQ: 확인된 사실만으로 답할 수 있는 질문만(등록 여부, 진행 흐름, 서류 확인, 개인정보). 요금·무료 여부는 설정값 연동.

## 6. 공개 전 확인 목록 (사용자 몫, 관리자 화면에서 입력)
1. 상담 무료 여부와 요금 안내 문구
2. LINE·카카오 링크
3. 담당자 대응 언어·시간·통역 비용
4. 일본 사무소 상태
5. 게재할 YouTube 영상 주소와 게재 허가, YouTube 채널 「(주)미래결혼정보」와 운영자의 관계
6. 「未来国際結婚情報」 병기 여부
7. 등록증·보험증권 가림 이미지 게시 여부
8. 개인정보 처리방침 문구

## 7. 구현자에게 맡기는 것
- 페이지별 세부 레이아웃, 문장 다듬기(프롬프트 톤 유지), 이미지 구도.
- 생성 스크립트 구조(`site-src/` 아래 템플릿·언어별 문장, `python site-src/build.py`로 HTML 생성).
- 검증: 휴대폰 375px 가로 스크롤 없음, 3개 언어 전환, 상담 폼 → 관리자 표시(에뮬레이터), 설정값 반영, 콘솔 오류 없음.
